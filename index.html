Fireproof: The Definitive Guide

Powerful Data for Everyone

Fireproof is a lightweight embedded document database with encrypted live sync, designed to make browser apps easy. With its simple model for storing, processing, and accessing data, Fireproof is ideal for web applications that need real-time collaboration and offline-first capabilities. It offers an open source solution that's reliable, scales easily, and responds instantly.

Fireproof works with any JavaScript environment, offering a unified API that works both in React (with hooks) and as a standalone core API. Whether you're building a simple single-user application or a complex collaborative platform, Fireproof provides the tools you need. With this book, you'll learn how to leverage Fireproof's features including document CRUD operations, live queries, cryptographic integrity, and seamless sync capabilities.
