React Live Query and Document Hooks

Instant data-driven collaboration with React hooks.

Installation

The use-fireproof package provides both the core API and React hooks:

npm install use-fireproof

Or use with ESM.sh:

import { useFireproof } from "https://esm.sh/use-fireproof";

Creating a Database

Initialize a Fireproof database using the useFireproof hook. Each database is identified by a string name, and you can have multiple databases per application:

import { useFireproof } from "use-fireproof";

const { database, useLiveQuery, useDocument } = useFireproof("my-ledger");

Working with Documents

The useDocument hook provides a React-friendly interface for creating and updating documents. Documents are JSON objects with an _id field that can be auto-generated or explicitly set.

const App = () => {
  const { useDocument } = useFireproof("my-ledger");

  const { doc, merge, submit } = useDocument({ text: "", timestamp: Date.now() });

  const queryResult = useLiveQuery("timestamp", { descending: true });

  return (
    <div>
      <form onSubmit={submit}>
        <input
          value={doc.text}
          onChange={(e) => merge({ text: e.target.value })}
          placeholder="New document"
        />
        <button type="submit">Submit</button>
      </form>

      <h3>Recent Documents</h3>
      <ul>
        {queryResult.docs.map((doc) => (
          <li key={doc._id}>
            {doc.text} — {new Date(doc.timestamp).toLocaleString()}
          </li>
        ))}
      </ul>
    </div>
  );
}

Document Hook Methods

The useDocument hook provides several methods for managing document state:

  • merge(updates): Update the document with new fields
  • save(): Save the current document state
  • reset(): Reset to initial state
  • submit(e): Handles form submission by preventing default, saving, and resetting

Live Queries

The useLiveQuery hook provides real-time data querying capabilities. Queries are based on indexes and automatically update when the underlying data changes.

Basic Queries

// Query by timestamp, most recent first
const queryResult = useLiveQuery("timestamp", { 
  descending: true, 
  limit: 5 
});

// Query with specific key
const queryResult = useLiveQuery("agentId", { 
  descending: true, 
  limit: 5, 
  key: "llm-agent-1" 
});

Complex Queries

For more complex queries, you can use a function to define the index:

// Group and filter documents
const queryResult = useLiveQuery(
  (doc) => [doc.agent, doc.timestamp], 
  { descending: true, limit: 5, prefix: ["llm-agent-1"] }
);

Date-based Queries

const queryResult = useLiveQuery(
  (doc) => [doc.date.getFullYear(), doc.date.getMonth(), doc.date.getDate()],
  { descending: true, limit: 5, prefix: [2024, 11] }
);

Sortable Lists

Implement sortable lists using position-based queries:

function App() {
  const { database, useLiveQuery } = useFireproof("my-ledger");
  
  // Initialize list with evenly spaced positions
  async function initializeList() {
    await database.put({ list: "xyz", position: 1000 });
    await database.put({ list: "xyz", position: 2000 });
    await database.put({ list: "xyz", position: 3000 });
  }
  
  // Query items sorted by position
  const queryResult = useLiveQuery(
    (doc) => [doc.list, doc.position], 
    { ascending: true, prefix: ["xyz"] }
  );

  // Insert between existing items
  async function insertBetween(beforeDoc, afterDoc) {
    const newPosition = (beforeDoc.position + afterDoc.position) / 2;
    await database.put({ 
      list: "xyz", 
      position: newPosition 
    });
  }

  return (
    <div>
      <h3>Sorted List</h3>
      <ul>
        {queryResult.docs.map(doc => (
          <li key={doc._id}>
            {doc._id}: position {doc.position}
          </li>
        ))}
      </ul>
    </div>
  );
}

Real-time Updates

All queries automatically update in real-time when the underlying data changes:

function AgentUI() {
  const { useLiveQuery } = useFireproof("my-ledger");
  const conversation = useLiveQuery("timestamp", { 
    descending: true, 
    limit: 10 
  });

  return (
    <ul>
      {conversation.docs.map(log => (
        <li key={log._id}>{log.text}</li>
      ))}
    </ul>
  );
}
