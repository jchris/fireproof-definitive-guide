Reactive Architecture

Understanding live ledgers and reactive data flow - the foundation of the Fireproof advantage.

Reactive Development Made Easy

At its core, reactive programming streamlines application development by automatically synchronizing the user interface with changes in the underlying data state. Instead of manually managing UI updates, developers can focus on building features while the framework handles the synchronization.

If you've worked with React, you're already familiar with reactive development. When a component's state changes, React automatically re-renders to reflect the new state. This pattern is fundamental to modern web development:

// React example
setState({ greeting: 'Hello World' }); // UI updates automatically

Live Ledgers: The Next Evolution

Fireproof takes this reactive paradigm further with live ledgers. A live ledger serves as your application's state manager, providing a simple yet powerful way to interact with your data from anywhere in your application.

The core of Fireproof's reactivity is the ledger subscription system. In its simplest form:

const unsub = ledger.subscribe((changes) => {
  // update UI
}, true)

For React applications, this functionality is wrapped in intuitive hooks like useLiveQuery and useDocument:

// In your React component
const data = useLiveQuery('greeting');

Beyond Local State

While keeping state local to the UI is crucial for responsiveness, modern applications often need to share state across multiple users and systems. Live ledgers excel here by providing:

  • Local-first operation for immediate responsiveness
  • Automatic synchronization with cloud replicas
  • Seamless collaboration features
  • Integration with backend processes and APIs

This architecture is particularly powerful for applications like:

  • On-site experience apps (ticketing, scheduling)
  • Team data entry systems (inventory, supply chain)
  • Point-of-sale systems
  • Multi-user AI workflows with provenance tracking

By using live ledgers as the foundation of your application's state management, you get the benefits of reactive programming with the added power of seamless data synchronization and collaboration.
